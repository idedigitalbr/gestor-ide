# Pasta de Tarefas e Handover para o Codex

Esta pasta foi preparada para o **Codex** (ou outro agente de IA) dar continuidade ao projeto com total contexto, histórico e precisão.

## Arquivos Principais:
- **`PROMPT_CODEX_HANDOVER.md`**: Documento completo contendo todas as diretrizes, checklist de tarefas concluídas, arquivos alterados, pendências e instruções de execução.
- **`mockups/`**: Contém todos os 33 prints e imagens de referência visual enviados pelo usuário.

Para iniciar, abra e leia o arquivo [`PROMPT_CODEX_HANDOVER.md`](./PROMPT_CODEX_HANDOVER.md).
